# data/static/ — RouteWise Agentic

> **Owner:** Shared (real reference data becomes Workstream B). · **Layer:** static reference data.
> Small static reference datasets used across the app.

## What goes here (added as needed)

- A place gazetteer (e.g., "Colombo Fort", "Ella"), transport-mode metadata, and small lookup
  tables.

## Boundaries

- Keep it **small and committed**. Bulky or raw source data belongs in the gitignored `data/raw/`
  (Workstream B). No data files are added during A1 — foundation only.
